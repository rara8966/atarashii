# 客户演示说明

## 演示定位

本 Demo 已从单个风电样例扩展为“项目建档 + 标准库落库 + 八步审查 + 报告生成”的本地演示系统。客户给的 `土地用地标准` 文件夹已作为标准库来源接入，当前以 19 个已提取 DOCX 文件作为标准库种子，三个大 PDF 暂不进入运行包。

## 已完成内容

- 首页：支持新建项目、选择项目类型、填写建设单位和建设地点，并查看历史项目。
- 落库：项目档案、用地标准条目、项目标准匹配结果使用 H2 本地文件数据库保存。
- 标准库：启动后自动导入 476 条标准条目，覆盖 9 类项目类型。
- 项目隔离：每个项目拥有独立工作区，材料解析、字段修改、情形选择和报告草稿不会串到其他项目。
- 第六步土地利用：按当前项目类型展示标准条目，并支持“刷新并落库”生成匹配记录；对可识别的用地指标会自动估算上限，区分“通过 / 需关注 / 缺参数”。
- 风电标准实测：对“单机容量 3000kW、5 台风机、申报面积 0.38 公顷”的测试项目，可匹配 `表3.1.2 风电机组建设用地指标`，按 900 m²/台测算上限约 0.45 公顷，判定为“通过”。
- 材料解析：继续支持批量拖入材料、自动归档到八步、字段提取和实时校验。

## 验证口径

- 后端测试：`mvn test` 通过。
- 前端构建：`npm run build` 通过。
- 页面验证：新建“隔离验证铁路项目”后，工作台字段来自项目档案和待解析状态；第六步查询到 24 条铁路标准，刷新后落库 8 条匹配记录。
- 标准实测：新建“标准库实测风电项目”后，第六步按真实标准库刷新，首条结果为风电机组指标“通过”，并展示申报面积、装机容量、风机台数、单机容量和标准指标。

## 客户演示建议

1. 打开首页，先展示“落库项目、用地标准条目、项目类型”的系统库状态。
2. 新建一个项目，选择不同项目类型，例如“公路工程”或“新建铁路工程”。
3. 进入工作台后展示八步审查框架，说明每个项目的数据相互隔离。
4. 切到第六步“土地利用”，展示标准库条目和“刷新并落库”。
5. 再返回首页打开另一个项目，证明项目列表和本地数据库已经实际生效。

## 当前边界

- 标准库匹配已支持部分可结构化指标的自动测算，例如风电机组 m²/台、线路/道路 hm²/km、装机容量 hm²/MW 和条文内绝对面积上限。
- 对条文格式复杂或项目材料缺少长度、容量、台数等参数的情况，系统会标为“缺参数”或“需关注”，仍建议审查人员结合原文和主管部门意见复核。
