# 客户演示说明

本包只包含建设用地报批审查报告智能生成系统 Demo 的源码和演示文档，不包含本地大模型文件。

## 启动方式

最简单方式：双击根目录的 `启动.bat`。

启动器会自动检查 JDK、Maven、Node.js 和前端依赖。系统没有这些依赖时，会下载便携版到项目 `.runtime` 目录，不需要安装到系统，也不需要管理员权限。

依赖下载使用国内镜像：

- JDK：华为云 / 清华 Adoptium 镜像，官方 Adoptium 兜底
- Maven：阿里云 / 清华 Apache Maven 镜像
- Node.js：npmmirror 镜像
- Maven 依赖：阿里云 Maven 仓库
- npm 依赖：npmmirror registry

也可以在 VS Code 中打开本包根目录后，使用 Terminal -> Run Task：

1. policy-report: 启动前后端
2. policy-report: 启动前端
3. policy-report: 启动后端

正常演示时选择“policy-report: 启动前后端”。启动器完成依赖检查、构建检查和基础自测后，会自动打开浏览器。也可以手动访问：

http://127.0.0.1:5173/

后端接口地址：

http://localhost:8080/

## DeepSeek 测试

页面左侧“AI 配置”选择 DeepSeek，填写客户自己的 DeepSeek API Key 和模型名，例如：

deepseek-chat

API Key 只保存在当前浏览器本地，不写入源码包。

## 注意事项

1. 本包已排除 node_modules、target、dist、本地上传文件、本地状态库、自测临时数据和 `.runtime` 便携运行目录。
2. 首次运行会自动下载便携依赖并执行构建检查，时间取决于网络速度。
3. 本地 Ollama 不是必需项；客户没有本地模型也可以用 DeepSeek 完成演示。
4. 后续再次启动会复用 `.runtime`、Maven 本地仓库和 npm 缓存，速度会快很多。
