OCR + DeepSeek 审查链路

建设用地报批材料智能解析工作流

上传 PDF、Word、图片或扫描件后，系统先做结构化解析和 OCR，再隔离标准库文件，最后把全文分块交给 DeepSeek 输出可审查、可追溯的五段式意见。

Tesseract中文 OCR 引擎，chi_sim+eng，优先识别扫描件
DeepSeek运行时传入 API Key，生成完整审查意见
300MB后端上传上限已覆盖大体量土地标准 PDF
标准隔离标准库文件不再写入项目事实字段

主流程

1材料输入

项目工作台上传

支持 PDF、DOCX、TXT、PNG、JPG，可一把导入八步材料。

政策明白卡

作为审查规则和 AI 提示上下文，和项目材料分开管理。

2基础解析

Tika 文本抽取

优先读取 Word、可复制 PDF、文本文件中的原始内容。

类型识别

判断是项目材料、土地标准库、扫描图片还是疑似扫描 PDF。

3OCR 分支

Tesseract 优先

对图片和扫描 PDF 页面执行 chi_sim+eng OCR。

视觉模型兜底

当 Tesseract 无可信文本时，再走本地视觉模型补识别。

质量闸口

噪声太多或文本太短时拒绝污染后续审查。

4审查加工

字段抽取

提取申报面积、供地方式等项目事实字段。

标准库隔离

土地标准文件只进入标准匹配和 AI 审查，不写项目事实字段。

全文分块

长文本按配置分块，避免只看前几千字。

5结果输出

DeepSeek 审查

输出材料摘要、识别字段、需要改、可补充、风险提醒。

前端解析卡片

展示文本长度、字段数、校验项、AI 完整意见。

报告草稿

已解析材料可继续进入八步审查报告预览和导出。

本轮验证结果

  • OCR 图片生成扫描图识别 62 字，抽出“申报面积 12.3 公顷”和“供地方式 划拨”。
  • DeepSeek同一 OCR 文本进入 DeepSeek，前端展示完整五段式审查意见。
  • 风电 DOCX真实《电力工程项目建设用地指标（风电场）》识别为标准库文件，字段数保持 0。
  • 大 PDF59.2MB 标准汇编 PDF 触发扫描 OCR，90.5MB 上册 PDF 上传和 Tika 路径通过。

关键保护点

  • API KeyDeepSeek Key 仅由运行时请求传入，不写入代码和配置文件。
  • 标准文件标准条文用于比对和风险提醒，不覆盖项目名称、面积、供地方式等事实字段。
  • OCR 噪声识别文本会先过质量判断，低可信结果只提示，不进入事实抽取。
  • 可调页数扫描 PDF OCR 页数由 app.ocr-max-pages 控制，演示时可低页数快速验证。
